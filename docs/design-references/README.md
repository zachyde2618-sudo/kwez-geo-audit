# Design references

Two DESIGN.md files copied from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(commit fcc7028, MIT licence, see `LICENSE` in this folder). They describe other
companies' public websites and are here only as **reference** for the Kwez system in
`/DESIGN.md`, which follows the Kwez brand board in `docs/brand/kwez-brand-board.jpeg`. Never copy their colours, fonts, logos or names into the app.

| File | Source in the collection | What we take from it |
|------|--------------------------|----------------------|
| `warm-editorial.DESIGN.md` | `design-md/claude` | Light paper canvas, display headings with a quiet sans body, a single interface accent, hairline-led cards. (Its cream and coral colours belonged to the old Kwez look; the 2026 brand board replaced them.) |
| `data-dashboard.DESIGN.md` | `design-md/stripe` | Presenting numbers: tabular figures, quiet surfaces behind data, status chips, compact metadata rows. |

To try another system from the collection, browse `design-md/` there and add the file
here with a row in this table; then update `/DESIGN.md` on purpose.
